# Изменения

## 2026-07-31

- **Продажа нескольких телефонов из одного прихода.** Теперь можно продать любой
  оставшийся аппарат, даже если первый из этого прихода уже продан — и за наличные,
  и в рассрочку. Раньше система ошибочно писала «уже продан».
- **Простые статусы приходов:** Черновик / В наличии / Продано / Отменён / Возврат.
  Убран путаный «Частично продан» (приход с любым свободным аппаратом = «В наличии»,
  полностью проданный любым способом = «Продано»).
- **Отменённый приход теперь показывает «Отменён»** (раньше ошибочно оставался
  «В наличии»). «Возврат» — отдельный статус для реального возврата товара.
- **Точное сопоставление IMEI** в логике продажи и статуса (убрано сравнение по
  последним 6 цифрам, из-за которого два аппарата с одинаковым «хвостом» IMEI могли
  путаться). Поиск по частичному IMEI работает как прежде.
