# Статусы для мерчанта — памятка

Справочник рабочих статусов в **nasiya365**. Здесь только те статусы, которые
видит и использует мерчант в повседневной работе. Служебные (вкл/выкл записей,
внутренние технические) вынесены в конец.

> Смысл статусов выверен по коду приложения, а не по названиям полей.

---

## 1. Рассрочка — «Статус плана»

| Статус | Что означает |
|---|---|
| **Черновик** | План создан, ещё не проведён. Можно свободно менять. На клиента, склад и договор не влияет. |
| **Активный** | План проведён и действует, клиент платит по графику. Редактирование заблокировано. |
| **Завершен** | Все платежи по графику внесены — рассрочка закрыта. |
| **Просрочен** | Есть хотя бы один просроченный платёж (срок прошёл, не оплачен). |
| **Списан** | Долг списан (безнадёжный). План закрыт, платежей не ждём. |
| *(Отменен)* | План сторнирован, лимит клиента возвращён. Отдельно не выбирается — ставится при отмене. |

**«Статус договора»** (поле внутри плана):
**Не подписан** → **Подписан** (ставится автоматически при подтверждении) → **Отменен**.

---

## 2. График платежей (внутри рассрочки) — «Статус»

| Статус | Что означает |
|---|---|
| **Ожидает** | Платёж запланирован, ждём оплату (срок ещё не наступил). |
| **Частично** | Внесена часть суммы, остаток ещё должен. |
| **Оплачен** | Платёж внесён полностью. |
| **Просрочен** | Срок платежа прошёл, полностью не оплачен. |

---

## 3. Склад / Поступление — «Бизнес статус»

| Статус | Что означает |
|---|---|
| **Черновик** | Поступление создано, ещё не проведено. |
| **В наличии** | Товар оприходован, ничего не продано — лежит на складе. |
| **Частично продан** | Часть единиц продана, часть ещё на складе *(или всё продано, но разными способами)*. |
| **Наличные** | Вся партия продана за наличные. |
| **Рассрочка** | Вся партия продана в рассрочку. |
| **Возврат** | Поступление отменено / возвращено. |

**«Статус оплаты поставщику»**:
**Не оплачено** → **Частично оплачено** → **Оплачено**.

---

## 4. Продажа (заказ) — «Статус»

**Черновик** → **Подтвержден** → **Доставлен** (выдан клиенту) → **Отменен**.

---

## 5. Трейд-ин (обмен устройства) — «Статус»

**Черновик** → **Принят** (устройство принято) → **Отменен**.

*Дополнительно «Состояние» устройства: Отличное / Хорошее / Удовлетворительное / Б/У.*

---

## 6. Клиент — «Статус»

| Статус | Что означает |
|---|---|
| **Активный** | Можно оформлять рассрочки. |
| **Приостановлен** | Временно заблокирован, новые рассрочки нельзя. |
| **Черный список** | Рассрочки запрещены. |

---

## 7. Расход — «Статус»

**Черновик** → **Одобрен** → **Оплачен** → **Отменен**.

---

## 8. Оплата поставщику — «Статус»

**Ожидает** → **Завершен** → **Отменен**.

---

## 9. Договор — «Статус»

**Черновик** → **Подписан** → **Активный** → **Завершен** → **Отменен**.

---

## 10. Касса — «Статус»

**Открыта** (смена идёт) → **Закрыта** (смена закрыта).

---

## ⚙️ Служебные статусы (не рабочие, для справки)

- **Сотрудник-сборщик / Склад (объект)**: `Активный` / `Неактивный` — просто вкл/выкл записи.
- **Payment Transaction**: `Ожидает` / `Завершен` / `Отменен` — внутренняя запись платежа;
  мерчант её отдельно не ведёт, видит результат через график рассрочки.
