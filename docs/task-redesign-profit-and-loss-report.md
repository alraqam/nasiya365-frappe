## 6. Раздел «Продажи, оформленные за период»

Название:

```text
1. Продажи, оформленные за период
```

Описание:

```text
Показывает продажи, оформленные в выбранном периоде,
и прибыль, которая может быть получена по этим сделкам.
```

### Таблица

| Тип продажи | Продажи | Себестоимость | Маржа товара | Проценты по рассрочке | Общая прибыль |
|---|---:|---:|---:|---:|---:|
| Наличные | $850.00 | $800.00 | $50.00 | — | $50.00 |
| Рассрочка | $2 660.00 | $2 615.00 | $45.00 | $508.00 | $553.00 |
| **Итого** | **$3 510.00** | **$3 415.00** | **$95.00** | **$508.00** | **$603.00** |

### Соответствие данных

#### Наличные

```text
Продажи = Наличные — продажа
Себестоимость = абсолютное значение «Наличные — себестоимость»
Маржа товара = Наличные — маржа
Проценты = отсутствуют
Общая прибыль = Наличные — маржа
```

#### Рассрочка

```text
Продажи = Рассрочка — продажа
Себестоимость = абсолютное значение «Рассрочка — себестоимость»
Маржа товара = Рассрочка — маржа
Проценты = Процентный доход (потенциальный)
Общая прибыль = Рассрочка — маржа + Процентный доход (потенциальный)
```

#### Итого

```text
Продажи = наличные продажи + продажи в рассрочку
Себестоимость = себестоимость наличных + себестоимость рассрочки
Маржа товара = Итого маржа товара
Проценты = Процентный доход (потенциальный)
Общая прибыль = Потенциальная прибыль сделок
```

На UI себестоимость показывать положительным числом, не изменяя серверное значение.

## 9. Денежный формат

Требования:

- суммы выровнены по правому краю;
- два знака после запятой;
- пробел как разделитель тысяч;
- единый формат валюты;
- ноль: `$0.00`;
- отсутствующее значение: `—`;
- отрицательная сумма: `−$120.00`.

Пример:

```text
$3 510.00
$95.00
−$120.00
```

Создать одну общую функцию форматирования валюты.
